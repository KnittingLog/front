# 뜨개로그 (KnittingLog)

뜨개 프로젝트를 기록하고 친구들과 함께 뜨는(함뜨) React Native 앱입니다. Expo(SDK 57) + Expo Router + TypeScript로 만들었습니다.

## 실행

```bash
npm install
npm start          # Expo Go 앱으로 QR 스캔
npm run ios        # iOS 시뮬레이터
npm run android    # Android 에뮬레이터
npm run web        # 브라우저
npm run typecheck
```

## 백엔드 연결

앱의 모든 데이터는 백엔드([KnittingLog/back](https://github.com/KnittingLog/back)) REST API(`/api/v1`)에서 가져옵니다. 백엔드를 먼저 띄운 뒤 앱을 실행하세요.

```bash
cp .env.example .env.local   # EXPO_PUBLIC_API_URL=http://localhost:8000
```

- 주소에는 호스트와 포트만 적습니다(`/api/v1`은 앱이 붙임). 포트는 백엔드 `API_PORT`와 같아야 합니다.
- 백엔드는 `MODE=local`에서 `127.0.0.1`에만 열립니다. 실기기(Expo Go)에서 붙으려면 백엔드를 다른 모드로 띄우거나 같은 PC의 웹/시뮬레이터로 실행하세요.
- 가입하려면 서버 DB에 약관 문서(`policy_documents`)가 등록돼 있어야 합니다.
- 프로젝트 대표 사진을 올리려면 백엔드에 저장소 설정(`KNITTINGLOG_LOCAL_STORAGE_CODE`, `KNITTINGLOG_LOCAL_STORAGE_ROOT`)이 필요합니다.

### 계정 규칙 (서버 기준)

- 로그인 아이디·계정 ID: 영문 소문자·숫자·`_`·`.` 3~32자, 처음과 끝은 영문·숫자
- 비밀번호: 15~128자
- 가입하면 **비밀번호 복구 코드**를 한 번만 보여 줍니다.
- 로그인 토큰은 15분마다 자동으로 갱신됩니다(30일간 유지).

### 서버에 없어서 앱에서 뺀 것

| 기능 | 현재 동작 |
| --- | --- |
| 기록·게시글 사진, 게시글의 프로젝트 연결 | 입력란 제거 (서버는 글만 저장) |
| 게시글 좋아요 수 | 내가 눌렀는지만 표시 (서버가 좋아요 목록을 주지 않아 기기에 기억) |
| 받은 초대의 프로젝트 이름·보낸 사람 | 수락 전에는 표시 안 함 |
| 보낸 초대 목록 | 이 기기에서 보낸 초대만 '초대 취소' 가능 |
| 기록 시각 수정 | 내용과 뜬 시간만 수정 |
| 참여 시작일 | 첫 기록 날짜로 표시 |
| 기록 반응 | 서버가 허용하는 5종(❤️ 👏 👍 🎉 😮) |
| 다른 멤버가 올린 대표 사진 | 올린 사람에게만 보임 |

## 핵심 개념

- 모든 프로젝트는 한 가지 형태이고 **기본은 비공개**(나만 봄). 친구를 초대해 수락하면 상세 화면 맨 위에 **멤버 아이콘**이 생기고, 누르면 각자의 기록을 볼 수 있습니다.
- **상태·실·기록은 개인 소유**. 상태는 `진행중 / 보관 / 종료`이고, 종료는 프로젝트 종료가 아니라 *내 기록 종료*입니다(작업 기간 자동 표시).
- 멤버가 빠지는 경우

  | 케이스 | 프로젝트 방 | 개인 기록 |
  | --- | --- | --- |
  | 본인이 종료 | 남아 있음 (흑백 + "프로젝트 종료 유저입니다!") | 유지 |
  | 본인이 나가기 | 빠짐 | 혼자 진행하는 프로젝트로 남아 이어서 기록 가능 |
  | 방장이 추방 | 빠짐 | 혼자 진행하는 프로젝트로 남아 이어서 기록 가능 |

- **방장**: 친구 초대(방장만 가능), 멤버 추방, 방장 양도, 이름·대표 사진 수정. 멤버가 있으면 삭제·나가기 불가 → 양도하면 일반 멤버가 되어 나가기 가능. 혼자 남은 프로젝트는 바로 삭제.
- **프로필 공개 범위**: 전체 공개 / 친구 공개 / 비공개. 볼 수 없는 사람에게는 프로필에서 기록과 총 뜨개 시간이 가려집니다(함께 하는 프로젝트 안에서는 보임).
- **신고·차단**: 차단하면 서로의 프로필·게시글·기록이 안 보이고 친구 관계·요청·초대가 끊어집니다. 신고는 서버에 접수됩니다.

## 화면

| 경로 | 화면 | 기능 |
| --- | --- | --- |
| `/login`, `/signup` | 로그인 / 회원가입 | 아이디·닉네임·비밀번호 가입(SSO 없음), 가입 후 복구 코드 표시. 약관 링크 |
| `/` | 메인 | **내 프로젝트**: 받은 초대, `전체/진행중/보관/종료` 필터, 카드에 방장·공유 인원·기간(`26.09.10 ~ ing`)·내 상태. **피드**: 작품 자랑 게시글(좋아요·댓글·신고·차단) |
| `/project/[id]` | 프로젝트 상세 | 방장 👑 표시, `…` 메뉴(수정·친구 초대·방장 양도·나가기·삭제), 내 상태 변경. 맨 위 멤버 아이콘으로 각자의 진행상황·기록 전환. 내 기록: 하단 고정 작업바(타이머 + 단수 카운터. 기본은 카운터 2개만 보이고, 손잡이·타이머 영역을 잡고 위로 끌어당기면 전체가 펼쳐짐), 카운터 관리(표시·순서·추가·수정·삭제), 기록 추가. 다른 멤버: 프로필 이동, 친구 추가, 방장의 양도·내보내기 |
| `/project/new` | 새 프로젝트 | 이름·대표 사진·내 실·내 바늘·상태, 친구 초대(선택) |
| `/post/new` | 게시글 쓰기 | 글 |
| `/user/[id]` | 프로필 | 기록(공개 프로필만)·게시글, 친구 추가, 신고·차단 |
| `/mypage` | 마이페이지 | 프로필·계정 ID·소개·공개 범위·총 뜨개 시간, 뒤로가기 시 항상 메인으로, 내 기록 모아보기, 차단 목록, 약관 및 정책, 친구 검색·요청, 로그아웃 |
| `/logs` | 내 기록 모아보기 | 프로젝트 구분 없이 시간순, 프로젝트 이름 표시 |
| `/policy` | 약관 및 정책 | 이용약관·개인정보처리방침·커뮤니티 가이드 (초안) |

## 구조

```
src/
  app/            # Expo Router 화면
  components/     # UI 컴포넌트 (카드, 타이머, 기록, 기록 작성 시트 등)
  api/            # 백엔드 연결 (fetch 클라이언트, 엔드포인트, 서버 타입, 주소 설정, 인증 토큰)
  store/          # 전역 상태 (서버 데이터 캐시 + API를 부르는 액션)
  theme.ts        # 색상·폰트 토큰
  types.ts
```

화면은 `useStore()`의 `state`를 읽고 `actions`를 부릅니다. 액션은 `src/api/endpoints.ts`의 서버 호출을 실행한 뒤 메모리 캐시를 갱신하고, 실패하면 알림을 띄웁니다.
